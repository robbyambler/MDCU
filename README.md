# Matt Damon Cinematic Universe (MDCU)

This repo collects a tongue-in-cheek but internally consistent "Matt Damon Cinematic Universe" (MDCU), where many of Matt Damon's major film roles are treated as different aliases of a single individual whose life is shaped by law, war, black-ops, politics, pandemics, and space travel.

The goal is to provide:
- A narrative overview of the shared-universe concept.
- A detailed personal chronology that places each role on a single timeline.
- A Mermaid diagram you can render directly on GitHub or in any Mermaid-capable viewer.

## Files

- `mdcu-overview.md` – Universe rules and high-level life arc.
- `mdcu-timeline.md` – Detailed personal chronology table.
- `mdcu-diagram.md` – Mermaid flowchart source for the MDCU.

## GitHub rendering notes

GitHub can render Mermaid diagrams directly in Markdown files when fenced with a `mermaid` code block. If you view `mdcu-diagram.md` on GitHub, the diagram should render automatically. If not, you can paste the Mermaid block into any online Mermaid editor or a local Markdown+Mermaid tool.
